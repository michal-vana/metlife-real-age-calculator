# metlife-real-age-calculator
 interaktivní kalkulačka MetLife pro roadshow. Vývoj tabletové/kioskové aplikace, kde návštěvník na základě pár otázek o životním stylu získá vizuální vyhodnocení a MetLife CTA sdělení, propojené s LED panelem zobrazujícím anonymní agregované statistiky všech účastníků akce
